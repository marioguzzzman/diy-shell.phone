# Enclosure — the shell

The shell that houses the electronics. It's not just a case: the bone-conduction
transducer is hot-glued inside it, so the shell itself vibrates and becomes the speaker.

**Any shell works** — a real seashell is fine (see the [Assembly guide](../docs/assembly.md#step-9-glue-the-transducer-into-the-shell)).
The files below are a 3D-printable shell, if you'd rather print one.

## Files
- `hollowShell_full_new.3mf` — 3MF model (keeps print settings; open in a slicer like PrusaSlicer / Bambu Studio)
- `hollowShell_full.obj` — plain mesh (open in any 3D tool)
